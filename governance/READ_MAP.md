# 역할별 최소 열람표

모든 역할은 `START_HERE.md`를 읽는다. 아래에 없는 파일을 습관적으로 전부 불러오지 않는다.

| 역할 | 필수 열람 | 조건부 열람 |
|---|---|---|
| 총괄/운영 | `governance/*`, `continuity/CURRENT_STATE.yaml`, 대상 에피소드 상태 | 성과 분석 시 `channel/*` |
| Story Writer | Personality, Voice, World, `CURRENT_STATE.yaml`, 대상 brief/status | 집 장면이면 Home, 신체 개그면 Character |
| Continuity Supervisor | 대상 산출물, 관련 Canon, `CURRENT_STATE.yaml`, `REVEALED_FACTS.yaml` | 공간 장면이면 `continuity/sets/*`와 장소 Lock·이미지, 렌더 검수면 Edit Lock |
| Studio Producer | 승인된 script/review, Character, Edit Lock, 대상 Emotion Previz 템플릿 | 공간 장면이면 `continuity/sets/SPATIAL_CONTINUITY.md`, `SET_REGISTRY.yaml`, 장소 Lock·레퍼런스 |
| Renderer Developer | `docs/EDIT_JSON_REFERENCE.md`, 최신 Edit Lock, Renderer 코드, 대상 `edit.json`·오류 로그 | Set 메타데이터 검증 시 `SET_REGISTRY.yaml`과 asset manifest |
| 채널 분석 | `channel/PUBLISHING_EXPERIMENT.md`, 게시·성과 원장 | 작품 해석이 필요한 경우 대상 에피소드 brief |
