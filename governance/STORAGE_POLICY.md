# 저장 정책

## GitHub

코드와 자주 바뀌는 텍스트·상태의 단일 기준 저장소다.

- Renderer 코드와 테스트
- 운영 규칙과 역할 정의
- Canon 텍스트
- 연속성 상태와 공식 연대기
- 에피소드 brief, script, review, JSON
- 변경 이력

## ChatGPT Library

여기서 Library는 ChatGPT의 파일 Library를 뜻한다.

- 공식 Character·Home·Bubble 레퍼런스
- 생성된 기본 컷과 액션 프레임
- 공용/원본 오디오
- 최종 MP4와 대용량 산출물

Git에는 Library 자산의 정확한 파일명과 용도를 `canon/ASSET_MANIFEST.md` 또는 에피소드 manifest에 기록한다. Library 내부 식별자는 사용자에게 불필요하게 노출하지 않는다.

## GPT 프로젝트 소스

자주 읽는 고정 진입점과 레퍼런스를 제공한다. 자주 변경되는 승인 상태의 단일 원본으로 사용하지 않는다. 프로젝트 소스와 Git 문서가 충돌하면 Git의 최신 승인 상태와 확정 Canon 버전을 확인하고 Owner에게 보고한다.

## 임시 작업공간

재현 가능한 캐시와 실패 시안만 둔다. 공식 결정이나 유일한 원본을 두지 않는다.
