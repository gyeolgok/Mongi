# Mongi Home Lock V1.0

작성일: 2026-09-13  
상태: 공간 구조·대표 시점 2종 확정본 / 향후 4~6개 시점으로 확장 가능

---

## 1. 공간 한 문장 정의

> 작지만 정돈하려고 노력한 현실적인 구옥 원룸. 저렴한 생활용품 사이로 몽이의 차분하고 소박한 취향이 조금씩 보이는 집.

- 약 18㎡(5.5평) 직사각형 원룸이다.
- 낡고 처참하거나 궁핍을 과장한 공간이 아니다.
- 새집·호텔·감성 쇼룸처럼 넓고 완벽한 공간도 아니다.
- 생활의 흔적은 에피소드에 따라 늘고 줄지만, 공간 자체의 정체성과 배치는 바뀌지 않는다.

---

## 2. 절대 고정 평면 구조

현관에서 창문을 바라보는 방향을 기준으로 한다.

- **정면 끝 벽:** 창문 1개. 중앙보다 약간 왼쪽.
- **왼쪽 긴 벽:** 현관 쪽부터 간이주방 → 냉장고. 책상은 이 벽에 붙지 않는다.
- **오른쪽 긴 벽:** 방 안쪽 절반에 싱글침대. 머리는 창문 쪽, 발은 현관 쪽. 침대 위쪽 벽 상단에는 낡은 벽걸이 에어컨 1대가 있다.
- **창가 작업 공간:** 책상은 창문과 평행하게 두되 창문 벽에서 충분히 떼어 독립 배치한다. 가까운 옆벽과도 약 60cm의 간격을 유지하며 어느 벽에도 붙이지 않는다.
- **현관:** 출입문은 현관에서 창문을 볼 때 오른쪽 가장자리. 안쪽으로 열린다.
- **중앙:** 현관에서 창가까지 이어지는 좁은 생활 통로와 직사각형 러그.
- **현관 옆 수납장:** 침대 쪽에서 현관을 볼 때 출입문 왼쪽. 전경 A에서는 벽에 가려질 수 있다.

창문·출입문·주방·침대의 위치와 책상·의자·노트북의 방향을 바꾸거나 좌우 반전하지 않는다.

## 3. 고정 가구와 반복 소품

| 요소 | 고정 디자인 |
| --- | --- |
| 침대 | 낮은 흰색 원형 파이프 프레임의 싱글침대 |
| 침구 | 오트밀 시트, 크림색 베개, 더스티 세이지 이불, 발치 근처 넓은 크림색 가로띠 1개 |
| 책상 | 밝은 오크 상판, 단순한 흰색 금속 다리 |
| 의자 | 베이지색 접이식 철제 의자 |
| 노트북 | 실버 그레이, 중앙의 둥근 갈색 발바닥 스티커 정확히 1개, 브랜드 없음 |
| 조명 | 책상 위 둥근 갓의 흰색 스탠드 + 천장의 단순한 원형등 |
| 에어컨 | 약간 누렇게 바랜 소형 구형 벽걸이 에어컨 1대, 오른쪽 긴 벽의 침대 위쪽 상단, 크림색 배관 노출 |
| 주방 | 크림색 상판·상부장, 연한 세이지/민트 하부장, 작은 스테인리스 싱크, 1구 인덕션 |
| 냉장고 | 작고 오래된 느낌의 미색 2도어 냉장고 |
| 침대 옆 수납 | 반투명 서랍의 흰색 3단 플라스틱장 |
| 창가 | 아이보리 커튼, 테라코타 화분 1개와 작은 초록 새싹 |
| 바닥 소품 | 중앙의 좁고 긴 베이지 직사각형 러그 |
| 건물 흔적 | 따뜻한 아이보리 벽, 천장 가까이 노출된 크림색 배선관, 벽 모서리의 약한 사용감 |

반복 소품은 형태·재질·기본색을 유지한다. 브랜드·글자·새로운 장식 문양을 임의로 추가하지 않는다.

### 작업 공간 방향 규칙

- 책상 긴 면은 창문 벽과 평행하지만 창문 벽에서 떨어져 있으며, 가까운 옆벽과 약 60cm 간격을 둔다.
- 의자는 창문과 책상 사이에 놓고 등받이가 창문을 향한다. 앉은 몽이는 현관 쪽을 바라본다.
- 노트북 화면은 의자·창문 쪽, 발바닥 로고가 있는 뒷면은 현관 쪽을 향한다.
- A 시점에서는 노트북 뒷면과 발바닥 로고가 보인다.
- B 시점에서는 화면과 의자 등받이가 보이며 발바닥 로고는 보이지 않는다.

## 5. 공식 카메라 시점 V1.0

### A. 현관·주방 쪽에서 보는 전경

- 현관 가까이, 주방 앞에서 창문 쪽을 바라보는 약간 높은 눈높이의 3/4 와이드숏.
- 왼쪽 전경에 간이주방과 냉장고, 창문 앞에서 벽과 간격을 둔 책상·의자, 오른쪽에 침대와 낡은 벽걸이 에어컨이 함께 보인다.
- 현관 쪽에서 노트북 뒷면을 보므로 발바닥 로고가 보인다.
- 몽이가 중앙 통로나 침대 옆에 들어갈 여백을 남긴다.
- 첫 화의 기본 전경과 방 전체 소개 컷에 사용한다.

### B. 침대 쪽에서 책상을 보는 역방향

- 침대 발치/옆에서 현관 쪽을 바라보는 약간 높은 눈높이의 3/4 와이드숏.
- 카메라는 침대 머리맡·창문 쪽에서 현관을 대각선으로 바라본다. 벽에서 떨어진 책상, 노트북 화면, 창문을 등진 의자의 등받이를 측면 3/4 각도로 본다.
- 왼쪽에는 침대 일부, 안쪽에는 냉장고·주방과 정면 끝의 현관문이 보인다.
- 창문은 카메라 뒤에 있으므로 다른 벽에 새로 그리지 않는다.
- 에어컨은 동일한 오른쪽 긴 벽 상단에 고정되어 있지만 B의 화각 밖에 있으므로 보이지 않는다. B에 에어컨을 억지로 추가하지 않는다.
- 책상 작업, 카드값 확인, 온라인 쇼핑, 취업 준비 장면에 사용한다.

두 시점은 서로 다른 방이 아니라 정확히 같은 공간의 정·역방향이다.

### C. A를 비튼 현관·침대 쪽 3/4 전경

- 카메라는 A와 마찬가지로 현관 가까이에 두되, 침대 쪽으로 약간 옮긴 뒤 창문·책상을 향해 왼쪽으로 약 15~20도 회전한다.
- A보다 덜 정면이며 오른쪽 침대가 조금 더 큰 전경 요소로 보이고, 책상 상판과 노트북 뒷면은 사선으로 보인다.
- 왼쪽 긴 벽의 간이주방과 냉장고, 창문 앞 작업 공간, 오른쪽 침대와 벽 상단의 낡은 에어컨이 한 프레임에 유지된다.
- 노트북 뒷면의 발바닥 로고가 보인다. 책상·의자·노트북의 물리적 방향은 A와 동일하다.
- 몽이의 얼굴과 상반신을 보여주는 일상 대화·리액션 장면에서 A보다 자연스러운 깊이를 만들 때 사용한다.

A와 C는 같은 방향 계열의 카메라 변형이며, 가구를 움직여 만든 별도 배치가 아니다.

## 6. 변경 가능 요소

- 계절에 따른 이불 커버와 커튼. 단, 침대·창문의 형태와 위치는 유지한다.
- 책상 위 컵, 책, 서류, 충전기와 택배 상자.
- 음식, 빨래, 쓰레기봉투와 같은 에피소드성 소품.
- 낮·밤·비·눈·맑음과 그에 따른 창빛 및 실내조명.
- 정리 상태. 단, 가구가 사라지거나 통행이 불가능할 정도로 과장하지 않는다.

변형 소품은 에피소드가 끝난 뒤 자동으로 고정 설정이 되지 않는다.

## 7. 금지 사항

- 방 크기를 넓혀 침실·거실처럼 분리하기.
- 출입문, 창문, 침대, 책상, 주방의 위치 교환 또는 좌우 반전.
- 두 번째 창문·출입문·소파·TV·로프트침대 추가.
- 값비싼 붙박이 가구, 호텔 침구, 과도한 식물과 장식품 추가.
- 균열, 곰팡이, 파손, 쓰레기로 가난을 비극적으로 과장하기.
- 포토리얼·3D 렌더로 스타일 변경하기.
- 노트북 스티커의 개수·문양 변경 또는 브랜드 로고 추가.

## 8. 제작 운용 규칙

1. 새 에피소드마다 방을 텍스트만으로 재생성하지 않는다.
2. A 또는 B 공식 배경 이미지를 기본 레이어로 재사용한다.
3. 몽이와 에피소드성 소품만 별도 레이어로 배치한다.
4. 시간·날씨 변경은 구조와 고정 가구를 보존한 편집으로 처리한다.
5. 새 카메라 시점이 필요하면 먼저 평면도에서 카메라 위치와 방향을 정하고, A·B 이미지를 동시에 연속성 참조로 사용한다.
6. 새 시점이 확정되면 Home Lock의 공식 시점 번호를 부여한다.

향후 권장 확장 시점은 `C 책상 측면 중경`, `D 침대 정면 중경`, `E 주방 작업대 중경`, `F 현관에서 들어오는 숏`이다.

## 9. 설정 우선순위

1. Character Lock V1.0: 몽이의 외형·자세·표정
2. Personality Lock V1.0: 성격·반응·가치관
3. World Lock V1.0: 경제 상황·도시·생활 조건
4. **Home Lock V1.0: 집의 구조·가구·배경 시점**
5. Voice Lock 및 개별 에피소드 연출

개별 에피소드의 편의를 위해 Home Lock의 고정 구조를 임의로 바꾸지 않는다. 변경이 필요하면 V1.1 이상의 공식 개정본을 만든다.
