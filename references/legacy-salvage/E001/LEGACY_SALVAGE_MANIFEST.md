# E001 Legacy Salvage Manifest

Status: `SALVAGE / NON-CANON`

이 문서는 사용자가 다시 지정한 기존 제작 이미지 **2, 7, 8, 9, 10, 11, 12, 13번**에서 회수할 수 있는 연출 요소만 기록한다.

## Authority Boundary

이 자료의 권한은 **연출 참고**에만 한정한다. 아래 요소는 명시적으로 회수 금지다.

- 몽이의 외형, 체형, 얼굴 무늬, 귀·꼬리 구조, 색상
- Home 공간 구조와 방의 기하
- 침대·책상·창문·주방·문·조명 등 가구/고정 소품의 위치·형태
- 카메라 위치, 촬영 방향, 렌즈감, 프레임 범위, 공간 기준점
- 공식 Character / Set / Prop / Camera Reference로의 등록
- Character Lock, Home Lock, Set Registry, Canon Asset Manifest를 수정하거나 대체하는 근거

실제 제작에서는 Character는 최신 Character Lock, Home은 최신 Home Lock과 `continuity/sets/SET_REGISTRY.yaml`, 공식 이미지 기준은 `canon/ASSET_MANIFEST.md`를 우선한다.

## Salvage Items

### E001-LS-02 — 채용공고 클로즈업

- Source: 기존 이미지 2번
- Emotion: `신입` 공고를 발견한 직후의 기대가 `경력 우대` 문구 때문에 꺾이는 당혹감/허탈감.
- Composition: 화면 대부분을 채용공고 UI가 차지하고 몽이는 화면 가장자리 일부만 보여, **문제의 원인인 공고 문구**가 먼저 읽히게 하는 정보 중심 연출.
- UI: `신입 사원 채용`과 여러 `경력/경험 우대` 조건을 시각적으로 대비시키는 방식. 핵심 모순을 강조색과 묶음으로 즉시 인지시키는 아이디어.
- Time: 직접적인 시간 변화 회수 요소는 없음.
- Comedy timing: `신입`이라는 큰 약속 → 바로 아래 누적되는 경력 우대 조건 → 몽이의 속마음이라는 3단 박자.
- Do not salvage: 노트북 형태/스티커, 배경의 현관·주방 구조, 시점과 렌즈/카메라 기하, 화면에 보이는 몽이 외형.

### E001-LS-07 — 취침 직전 마감 알림

- Source: 기존 이미지 7번
- Emotion: 거의 잠든 상태의 무방비함과 휴식 직전의 평온.
- Composition: 이불 속 몽이보다 전경의 스마트폰 알림이 먼저 눈에 들어오게 하여 **평온을 깨는 사건**을 시각적으로 선행.
- UI: `지원 마감 오늘 23:59`처럼 마감 시간만 강하게 읽히는 모바일 알림 카드.
- Time: 깊은 밤, 달빛/청색 계열의 조명으로 낮의 구직 장면과 확실히 분리하는 서사적 시간 전환.
- Comedy timing: 잠들기 직전 `띠링` 한 번으로 상황을 뒤집는 interruption beat.
- Do not salvage: 침대/창문/벽 장식의 구조와 위치, 야간 Home 배치, 카메라 위치 및 프레임 기하, 몽이 외형.

### E001-LS-08 — 알림 확인 후 즉시 놀람

- Source: 기존 이미지 8번
- Emotion: 졸림 → 즉각적인 경악. 눈과 입, 귀 움직임을 크게 사용한 **반응 강도의 급상승** 아이디어.
- Composition: 같은 사건 공간에서 스마트폰 알림을 유지하면서 몽이의 반응을 더 크게 보여 `원인 → 반응`을 연속적으로 읽히게 함.
- UI: 직전 컷과 동일한 마감 알림을 반복 노출해 관객이 이유를 다시 해석하지 않아도 되게 하는 연속성 아이디어.
- Time: 7번과 동일한 밤을 유지하여 두 컷이 즉시 이어짐을 강조.
- Comedy timing: 7번의 작은 `띠링` 뒤 한 박자 후 `앗?!`으로 폭발시키는 reaction beat.
- Do not salvage: 귀의 정확한 형태/각도 자체, 얼굴 비율, 침대·창문 배치, 카메라 기하.

### E001-LS-09 — 급히 지원서 작성

- Composition: 몽이의 집중 행동과 진행률 UI를 한 화면에 병치하여 **캐릭터의 노력 + 남은 작업량**을 동시에 전달.
- UI: `지원서 작성 70% / 첨부파일 0% / 최종 제출 0%`처럼 3단계 진행 상황을 단순한 체크/진행률로 시각화.
- Time: 밤을 유지하되 책상 조명의 따뜻한 국부광을 더해 `쉬는 시간 → 다시 일하는 시간`으로 전환된 느낌.
- Comedy timing: 침대에서 튀어나온 직후 이미 70%까지 달려온 과감한 시간 압축.
- Do not salvage: 책상과 침대의 상대 위치, 창문 위치, 램프/컵/노트북 디자인, 카메라 시점, 몽이 외형.

### E001-LS-11 — 제출 버튼 직전

### E001-LS-12 — 지원 완료

- Source: 기존 이미지 12번
- Emotion: 긴장 해소와 작은 성취감. 과도한 승리보다 `해냈다`에 가까운 기쁨.
- Composition: 완료 팝업을 상단 중심에 두고 아래의 몽이 반응과 체크 완료 노트를 함께 보여 결과와 감정을 한 번에 마감.
- UI: `지원이 완료되었습니다!`라는 단순한 성공 피드백과 확인 버튼. 이전 컷들의 진행 UI가 한 문장짜리 성공 상태로 정리되는 방식.
- Time: 심야 상태를 유지하여 `늦었지만 결국 제출했다`는 맥락 보존.

### E001-LS-13 — 제출 후 침대에 쓰러짐

- Source: 기존 이미지 13번
- Emotion: 성취감보다 피로가 먼저 오는 안도/탈진. `일단 하나는 했다.`의 작고 현실적인 자기 인정.
- Composition: 몽이를 침구 위에 넓게 눕혀 힘이 빠진 상태를 크게 보여주고, 말풍선은 짧게 유지해 감정의 여백을 확보.
- UI: 별도 디지털 UI 없음. 짧은 말풍선과 전경 메모가 잔여 서사 정보 역할.
- Time: 같은 밤의 끝. `알림 → 급작업 → 제출 → 다시 침대`로 원점 회귀하는 시간/행동 구조.
- Comedy timing: 거대한 긴급 작업 뒤 결론은 거창한 성공 선언이 아니라 `일단 하나는 했다.`라는 저에너지 punchline. E001의 정서적 착지 참고 가치가 높음.
- Do not salvage: 침대/창문/책상 배치, 누운 자세에서 드러나는 캐릭터 비율을 모델시트로 사용하는 것, 카메라 기하.

## Sequence-level Salvage

8개 이미지를 개별 복제하는 것보다 다음 **연출 리듬**을 회수하는 것이 핵심이다.

`공고의 모순 발견(02) → 잠들기 직전 마감 알림(07) → 놀람(08) → 급작업(09) → 업로드 지연(10) → 마지막 제출 버튼(11) → 완료/해방(12) → 침대로 복귀해 탈진(13)`

특히 07–13은 `평온 → interruption → reaction → acceleration → delay → anticipation → release → exhausted landing`의 코미디/감정 곡선 참고자료로 관리한다.

## Registration Rule

이 디렉터리와 본 Manifest는 **Canon 등록 문서가 아니다.** 여기에 기록된 이미지는 `canon/ASSET_MANIFEST.md`의 Official Character/Home/Camera reference 목록에 추가하지 않으며, `continuity/sets/SET_REGISTRY.yaml`의 Set/Camera reference로도 등록하지 않는다. 향후 E001 제작자가 이 자료를 사용할 때는 연출 아이디어만 추출하고, 실제 공간·가구·몽이 외형·카메라 기하는 최신 공식 Lock과 승인된 Previz를 다시 적용해야 한다.
