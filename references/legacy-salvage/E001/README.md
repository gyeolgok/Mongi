# E001 Legacy Salvage References

이 디렉터리는 E001의 기존 제작 이미지 중 **연출만 회수할 가치가 있는 비공식 참고자료**를 관리한다.

## Status

- Classification: `SALVAGE`
- Scope: emotion / composition / UI presentation / time-of-day transition / comedy timing
- Authority: **NON-CANON / NON-SET-REFERENCE / NON-CAMERA-REFERENCE**
- Episode: `E001`

## 절대 사용 금지

이 디렉터리의 자료는 다음 기준으로 사용해서는 안 된다.

1. 몽이의 공식 외형, 체형, 얼굴 무늬, 귀·꼬리 구조, 색상 기준
2. Home의 공간 구조, 가구 위치, 고정 소품 형태 또는 배치 기준
3. 공식 Set Reference 또는 Camera Reference
4. 카메라 위치·촬영 방향·렌즈감·프레임 범위 등 공간 기하 기준
5. Character Lock / Home Lock / Set Registry / Canon Asset Manifest를 대체하거나 수정하는 근거
6. 새 공식 Camera ID 또는 Set/Prop ID 등록 근거

공식 제작 시 몽이 외형은 Character Lock, Home 공간과 가구는 Home Lock 및 `continuity/sets/SET_REGISTRY.yaml`, 공식 시각 자산은 `canon/ASSET_MANIFEST.md`를 따른다.

## 허용되는 회수 범위

- 감정의 전환과 강도
- 캐릭터와 화면 요소의 상대적 강조 방식
- 화면 안 UI 정보의 단계적 노출 방식
- 낮 → 저녁 → 밤처럼 시간 변화를 서사 진행 신호로 쓰는 방식
- 알림 → 놀람 → 급행동 → 제출 → 탈진으로 이어지는 코미디 리듬
- 화면 밀도, 정보 우선순위, 컷 간 반응 타이밍 아이디어

세부 항목은 `LEGACY_SALVAGE_MANIFEST.md`를 따른다.

> 이 자료는 "그대로 재현할 그림"이 아니라 "연출 문법을 분해해서 회수하는 레퍼런스"다.
